    ℹ️ How to Use

    To create a new post: Click "New Post" in the sidebar. Fill in all fields, then click "Publish Post." The post is automatically saved to GitHub and will appear live on your site within a few minutes.

    To edit a post: Click the Edit button on any post in "All Posts." Change what you need, then click "Save Changes."

    Images: Upload photos to your GitHub repository's /images/ folder, then paste the URL here like https://validateyourvision.com/images/your-photo.jpg — or use any public image URL from Pexels, etc.
